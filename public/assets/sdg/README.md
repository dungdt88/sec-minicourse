# SDG icons

The content file points each goal at `assets/sdg/vi/sdg-01.png` … `sdg-17.png`. Put the official
Vietnamese icons there (PNG, square, any size from 200 px). Until a file exists, the app draws a
tile in the goal's official colour with its number and Vietnamese title, so nothing breaks.

## Licence (checked 25 October 2026)

The UN "Guidelines for the use of the SDG logo including the colour wheel and 17 icons" allow
**informational, non-commercial, non-fundraising** use of the 17 icons **without prior permission**.
This course is that kind of use (a school learning tool, no sale, no fundraising). Conditions:

- Use each icon whole, including its goal text; do not crop, recolour or redraw it.
- Link to the UN SDG website (https://www.un.org/sustainabledevelopment/) and include the UN's
  disclaimer that the material has not been approved by the UN. The SDG picker shows this
  (UI string `sdgCredit`, overridable from the content file); keep the English wording from the
  guidelines on anything printed for the competition.
- Commercial or fundraising use needs a UN licence. If the board game is later **sold** with SDG
  icons printed on it, that is a different use: request permission first via the form on
  https://www.un.org/sustainabledevelopment/news/communications-material/.

Sources: UN SDG communications materials page and the guidelines PDF linked from it
(https://www.un.org/sustainabledevelopment/wp-content/uploads/2023/09/E_SDG_Guidelines_Sep20238.pdf).
Re-check the current guidelines before launch; they are revised from time to time.

## Where to get the Vietnamese set

listed there). A Vietnamese set is usually available from the UN in Viet Nam country team or the
Ministry of Planning and Investment's SDG materials. I could not confirm an official Vietnamese
download page, so the mentor should obtain the set, check it is the official one, and record the
