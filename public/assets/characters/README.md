# Character art

The app ships with simple SVG placeholder characters drawn in code (`src/art/Character.tsx`):
Sóc Hạt Dẻ (squirrel), Gấu Mật (bear), Thỏ Bông (rabbit) and Cú Mèo (owl), each with neutral,
happy, thinking and oops expressions. They are original work made for this project and belong to
the client with the rest of the code.

To use commissioned or licensed artwork instead, put the files here and add `images` to the
character in the content file, e.g.

```json
{ "id": "gau", "name": "Gấu Mật", …,
  "images": { "neutral": "assets/characters/gau-neutral.png", "happy": "assets/characters/gau-happy.png",
              "thinking": "assets/characters/gau-thinking.png", "oops": "assets/characters/gau-oops.png" } }
```
